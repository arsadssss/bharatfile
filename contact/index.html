Frequently Asked Support Questions

Why did a large PDF fail to process on my mobile phone?
Because all processing occurs in local device memory (RAM), very large PDFs (e.g. 100+ pages or 100+ MB) may exceed memory limits on entry-level mobile devices. We recommend processing very large documents on desktop browsers or splitting the document into smaller page chunks first using our Split PDF tool.
Are my processed documents stored anywhere?
No. Processed files exist only in temporary browser memory unless you explicitly download them. The Document Organizer library uses your local browser's IndexedDB storage and is never uploaded to any remote server.
